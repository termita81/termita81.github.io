## Phase 2: CSS Styles (45 min)

- [ ] Define CSS custom properties for colors, spacing, and layout
  - Create a `styles.css` file and import it in `index.html`
  - Variables:
    - `--primary` (brand base)
    - `--secondary` (accent)
    - `--background` (light theme)
    - `--surface` (card background)
    - `--text-primary` (contrast color)
    - `--spacing-base` (8 px) + derived scales
- [ ] Build a mobile‑first layout using Flexbox and Grid
  - `<body>`: full‑width, min‑height 100vh, background
  - Sections (`#log`, `#history`, `#settings`) hidden by default, toggled via `data-active`
- [ ] Style the bottom tab navigation bar
  - Fixed to viewport bottom, full‑width, high‑contrast icons + labels
  - `::after` underline indicator that animates on click
- [ ] Style form inputs and labels
  - Padding (`var(--spacing-base)`), border radius, subtle box‑shadow
  - Focus state: `outline` with `var(--primary)`
- [ ] Create reusable card and table components
  - Card: `border-radius`, `box-shadow`, padding, margin‑bottom
  - Table: sticky header, zebra striping, responsive collapse for narrow viewports
- [ ] Ensure tap targets meet the 44 px minimum
  - Buttons, icons, table rows have `min-height` and `min-width` 44 px
- [ ] Verify across desktop and a 375×667 mobile viewport
- [ ] Document known cross‑browser quirks (e.g., Safari Flex‑gap support)
- [ ] Prepare a QA checklist for CSS variable usage and responsive breakpoints
